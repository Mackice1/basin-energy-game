# 厂站两层布局（V15）

基地地图只显示完整电热站，点击厂站进入独立站内3D布局；「返回基地」返回原地图。风机、光伏、变电站、电池仍在基地。电与热需求继续从需求面板设置，站内不虚构居民或工厂负荷。本批用电热站验证通用的厂站/设备父子关系，没有实现蒸汽火电。

## 使用

1. 基地建造栏选择「电热站」，放置空厂站。
2. 点击整体站或选中后「进入电热站内部」。站内可建设电热水锅炉、储热、隔离换热器；选择/移动/连接/参数/线路/拆除均针对内部设备。
3. 站内地面为48×48布局网格，2单位吸附；真实设备占地不得越界或重叠。内部布局坐标独立于基地地形，不把设备分别占在基地地图。
4. 锅炉→热储/换热器、热储→换热器是站内90/60°C线路。换热器70/40°C出口和锅炉AC输入成为基地边界端口。
5. 基地「连接」时点击厂站会列出可用的具体锅炉/换热器端口。多台设备时需明确选哪台，不自动虚构公共母线或重复容量。变电站→厂站AC入口；厂站热出口→外部热需求。站内不能跨父厂站直接拉主温区热管。
6. 选整个站后「出线」列边界线路；站内选择设备后「设备线路」可改容量/断线。热线路仅MWth、损耗固定0，转换损失仍在设备内核中计。
7. 模板面板可确认应用「电热完整链示例」，包含风光、变电站、一个内部有三设备的电热站及独立电热需求。可撤销。

## 计算与状态

厂站容器没有额定功率、库存或产能变量。AC输入、热输出、热库存仅汇总内部设备实际报告；实时和GLPK直接使用同一套内部设备/线路且只求解一次。外部连线在数据层直接绑定真实内部端口，界面将端点映射为整体厂站边界，绝不再计算一份“厂站发电”。

打开内部布局不会复制模拟器：暂停、1–60整数倍速、天气、CSV边界、能量积分都由基地同一时钟驱动。参数及删除确认等编辑弹窗会阻止推进；返回不重置时钟、库存或天气。分析结果仍独立，不回写实时状态。

内部移动仅修改 interior_x/interior_z，整体移动仅修改厂站基地x/z，不改变任何能量库存、端口限制或内部相对布局。删除整个站会一并删除内部设备和关联内外线路，有明确确认且可撤销。删除设备会移除它的库存，不做免费转移；撤销恢复完整原状态。

## 持久化与边界

schema6 / model15新增stations、next_station_id，以及设备parent_station_id、interior_x、interior_z。父容器只包含id/name/x/z，禁止嵌套、伪容量或伪库存；设备ID与厂站ID不相撞。内部及外部占地分别校验，父厂站仍受基地地形禁建/坡度限制。

兼容旧schema3/4/5：旧平铺热设备保持原样，不自动搬动或改变网络；可与新厂站并存。恢复与撤销后暂停×1。当前没有给其他复杂电厂强套未实现内部系统，也没有蒸汽压力、水力、给水/冷却回路。

云端实际运行验证见 STATION_VALIDATION.md；桌面导出仍未验证。
