# 2026-10-15 地图、设备及建造反馈打磨

本轮基于现有重建版继续开发，未重做V2；不改变能量模型、CSV优先级、存档schema或三种设备范围。

## 变化
- 地图：将地表宏观色差改为更大尺度的暖砾石/冷岩屑变化，保留原地形高度、禁建区和坡度规则。
- 风机：基础碎石、检修台阶/把手、塔脚法兰、机舱通风口/风向标和变流器细节。
- 光伏：缓存的电池栅线纹理、深蓝玻璃反光、碎石床及逆变器基础。
- 变电站：储油柜、双侧散热器、瓷套管与顶部端子、检修柜细节。
- 建造及移动：绿色/红色贴地占地边界，悬停实时显示不能放置的原因；移动前可看预览，非法点击不改变原设备。Esc退出，合法移动及撤销保持已有规则。
- 选择：除了端口也能点击设备模型；连线仍只按端口拾取。移动中改选其他设备会取消移动，防止旧设备预览误导。
- 浅色透明界面保持不变；装饰资产仍不是施工设计模型。
