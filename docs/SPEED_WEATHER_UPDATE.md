# V13 交互更新：整数滑条与天气球

2026-10-15。在已持久化V13基础上修改，保留GLPK和五设备模型，未扩展热/氢或在线天气。

## 已实现

- 固定1/5/10/60档位改成线性滑条，范围1–60，step=1，每次调整一倍；不显示单独的1倍参考刻度。
- 右侧数字输入框与滑条双向同步，接受范围内整数。小数、非法文本、非有限值、越界值拒绝，恢复原值并显示说明。数值等于整数的1.0会规范显示1。
- 暂停仍独立；调速不会启动模拟。同值外部刷新不会冲掉正在编辑的文本；读档仍暂停并复位1倍，不改变既有存档格式。
- 顶部正中为原创矢量圆形天气球，展示同一模拟时刻的全局背景风速与太阳辐照资源状态。轻动画只跟随模拟时间，暂停保持；没有随机天气。
- 悬停提示风速、辐照、温度、模拟时间、数据来源与边界。云量/降雨未知，不据辐照推断晴天、昼夜或降雨；未绑定真实地理位置，设备专属天气可能与全局值不同。
