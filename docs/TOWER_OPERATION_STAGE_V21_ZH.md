# V21：塔式熔盐供热、储热与昼夜蒸汽发电

2026-10-17。基于完整V20.1；原100面4×4m、四圈镜场和25m塔保持米制。新增可运行“塔式熔盐站”，旧“塔式未投运预览”仍保持零端口、零出力，不因加载旧存档自动投运。写出schema12/model21，读取schema3–11。

## 流程与来源

DNI太阳辐照 → 定日镜场/塔接收器 → 565/290°C熔盐 → 双罐储热（可直接旁路）→ 盐水蒸汽发生器 → 汽轮发电机 → 干冷凝汽器 → 给水泵 → 蒸汽发生器。

盐回路独立于旧300/200°C导热油和90/60°C水。没有盐油换热中间环节，不能用油罐当盐库存，也不能重复将同一股热同时发电和供热。蒸汽侧复用V20固定1MPa/280°C入口、10kPa凝汽与相同焓点；它是低压教学循环，未声称具备商业565°C高压再热循环的效率。盐水换热端差充分，但未模拟流量/压力/温度动态。

原始依据：
- [NREL/SAM塔式系统说明](https://samrepo.nlr.gov/help/power_tower_systems.html)：定日镜聚焦DNI至塔接收器，工质向蒸汽动力岛传热，可配热储能。
- [DLR等《Blueprint for Molten Salt CSP Power Plant》](https://elib.dlr.de/141315/1/Blueprint%20for%20Molten%20Salt%20CSP%20Power%20Plant.pdf)，§9.5：Solar Salt物性随温度变化，cp=1443+0.172T J/(kg·K)、ρ=2090−0.636T kg/m³。模型取常量cp=1500、ρ=1800作为简化。运行温区565/290°C；不是新材料或厂家性能认证。
- [NREL热储相关报告](https://www.nrel.gov/docs/fy24osti/88400.pdf)：565/290°C常规硝酸盐运行温区参照。
- 蒸汽焓点、质量与电热核算源见V20指南，镜场公开航拍依据见V20.1指南。

## 教学热模型与账本

镜面总面积固定A=100×16=1600m²。接收器面积参数只读，不能不改变地块/几何就扩大功率。

I=A×DNI/10⁶ MW；光学到达=I×0.60；盐可用热=I×0.60×0.90。

0.60为教学等效光学效率，汇总余弦、遮挡、反射、截获等损失；0.90为教学等效接收器效率，并非厂家曲线或光学追迹结果。不另乘水平面sin太阳高度，不把POA/GHI当DNI，不从POA回推DNI。夜间、太阳高度≤0或is_day=false时太阳输入和可用热均为0。天气快照严格校验DNI、太阳高度/方位、环境温度和昼夜状态。

800W/m² DNI：太阳入射1.28MW，光学未捕获0.512MW，等效接收器损失0.0768MW，可用盐热0.6912MW。取热泵/追踪辅电=实际取用盐热的2%；无接收路径、需求或充热空间时显式记录弃热，不凭空写入库存。

运行镜面使用天气太阳方向与镜心指向塔接收器的角平分法线；夜间镜面水平收拢。视觉跟踪不意味着已求得逐镜光学效率；功率仍使用上述等效系数。停采时需真实工程的偏焦/排盐/防过热保护，本版仅作安全限流和未利用太阳能记账，未作局部热流安全分析。

## 有限双罐储热

默认可用容量0.5MWhth，充热上限0.8MWth、放热上限0.1MWth，充/放效率各0.98，可用库存按0.005/h指数衰减。储罐循环辅电为实际充/放热功率的1%，独立于接收器和蒸汽岛辅机，不重复收费。同一步禁止充放并行。

E_after_loss=E_before×exp(−0.005Δt_h)
E_next=E_after_loss+0.98×Q_charge×Δt_h−Q_discharge×Δt_h/0.98。

先按库存和剩余容量裁剪热流，再更新能量；不靠事后clamp掩盖溢出。盐账显式分出充热、放热、转换损失、自放热、库存、SG盐输入与辅电。热端565°C和冷端290°C固定，SOC表示可循环盐的冷热份额，不是温度线性下降。满罐多余太阳能弃用，空罐夜间不能发电；0.5MWh并不意味着覆盖整夜，满功率忽略待机损失约可放4.9小时。

可用焓差=1500×275=412.5kJ/kg；0.5MWh对应约4363.64kg盐。每只罐均容纳全部库存，不将容量均分两罐；按ρ=1800得有效体积2.424m³/罐，加20%空置率后几何体积3.030m³/罐。容量改变时两罐真实尺寸同步变化并重新校验占地。

这是“已经预热完成”的固定温区运行模型。E=0表示盐都在290°C冷端，不是室温冷启动；初次熔盐、升温底能、冻结保护电加热、冷罐保温温度动态均未模拟。指数待机损失只是可用焓的教学近似，不能当作物理UA模型。

## 蒸汽、电力与冷却

盐SG默认热输入上限0.1MWth、盐水热传递效率0.97、SG泵控辅电=热输入的0.5%。蒸汽质量、汽轮轴功、毛电、给水泵电和凝汽排热均沿用V20相同焓点，并分别记录油输入与盐输入。

每100kW盐热输入，毛电约19.043kW；循环净电约16.949kW（扣SG泵控、冷却风机与给水泵），凝汽排空气约77.004kW。全站净贡献还要扣接收器及盐罐泵，UI不把循环净电当全站净电。凝汽器受环境温度和有限干冷容量约束，热天超出固定低压工况包络停止。凝汽废热不能冒充90/60°C可售热。

所有转换辅机必须得到独立风光或此前储存的电池电，禁止本时段汽轮毛电回供任何转换/辅机，也禁止电池同一步被汽轮充入又放出用于自举。普通电负荷、合法电池充电或有限外送可接收汽轮电。无外电、断盐管、断循环质量端口或缺冷却能力均不能免费产电。

## 两层空间、操作与数据

站地160×160m=25600m²；内区120×120m=14400m²包含于站地，不重复计地。100镜维持18/30/42/54m四圈14/20/30/36面，预留东西径向通道。运行塔接收器的控制柜/端口固定在中心，每站最多一台，实际塔和镜场由场站几何显示一次。流程设备不能占据定日镜扫掠区、塔基或服务屋，旧预览不开放运行设备。

“塔式熔盐昼夜发电示例”从空盐罐开始，使用内置晴天天气和模拟时钟，无需CSV；示例1MWh电池初始库存0.5MWh，是明确给定的外部辅助电储备，不作为太阳热。暂停冻结模拟时间与全部库存；倍速只改变每实际秒推进的模拟时间。存读档保留塔/盐/蒸汽和原有各能量账本。CSV仍可覆盖明确DNI与天气，缺DNI时保留并标识教学DNI，不默默把POA映射为DNI。

优化采用schema6/tower_stage1_v1快照，仅有塔设备时出现；旧场景快照保持原格式。GLPK使用同一套盐物性、限额、互斥和能量方程，解后独立复核热/电/质量/库存与外电来源。实时调度仍是有界启发式，不保证与多时段最优计划拥有相同分配；物理边界和守恒一致。塔式模型不包含经济玩法、装机优化、逐镜遮挡优化或高保真热工瞬态。

验证与真实截图记录在 evidence/tower_stage/；可重复全回归入口 tools/run_v21_regression.py。
