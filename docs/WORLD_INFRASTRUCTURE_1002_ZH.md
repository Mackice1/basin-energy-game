# 大地图基础设施视觉细化 · 1.0.0.2 同轮增量

## 内容

- 三座既有外送支撑改为收分格构塔、垂直于走廊的横担、悬垂绝缘子、分裂导线/间隔棒、弧垂与地线。官方工程参考和示意边界见 [外送走廊说明](EXPORT_CORRIDOR_VISUAL_1002_ZH.md)。不新增电压、回路、容量、相数或交直流模拟。
- 公路原进出端和通达关系、1.5单位路面宽度保持不变；东段可见中心线平缓南移绕开三塔基础，改连续贴地网格，补灰褐色碎石路肩、路缘、轮迹色差、近景中心虚线/边线和维护接缝。路肩仅是装饰，不扩大碰撞或可建设区。
- 地表保留原高度场、控制权重和4种512px材质；新增同尺寸1024px预烘焙颜色图，表现矿物色差、山前冲积纹理、沙纹和盐地细脉。没有新shader采样、动态噪声、昂贵材质层或高分辨纹理。
- 原水气路线、勘察框保持逐段采样位置、box几何和材质颜色，仅把独立节点合批。交通高亮沿新的纯视觉道路绕行。

## 成本控制

- 正交相机固定距离不适合距离LOD，因此按可见跨度切换：塔线65以下用近景，公路115以下显示细标线。
- 塔线每级5个共享材质批次，近17,748/远4,452三角形；隐藏级不绘制。路面1批，近景细节再1批。
- 没有新增运行、调度、碰撞、输入或持久化节点；不在每帧重建几何。全局抗锯齿/阴影/相机参数未改。

## 同场景原生GUI实测

原验收使用 Godot 4.6.3 Compatibility、Mesa llvmpipe CPU 软件渲染；相同暂停示例场景和相机，在 1440×900 / 1024×768 的近、远四档视图比较。最终绕塔修订后的帧时相对原基线为 **−5.3% 至 +4.8%**。短时共享 CPU 环境存在波动，结果有快有慢，不能据此宣称性能提升、流畅或硬件 GPU 达标。绘制批次减少不自动等于帧时改善。

此处是原验收观察，不是公开整理时的新性能测试。原始截图、进程指标、运行日志和状态快照不随公开源码发布；早期修订的图片也不作为最终公开验收图片提供。

## 限制

保留压缩的电网跨距，但已修正道路穿塔基的视觉问题：道路中心线距塔中心最近4.118地图单位，塔基保守半径1.70、路肩半宽1.02，剩余约1.40几何余量。这不是按真实UHV安全间距重建；外送4MW仍是已有教学模型容量。材质/几何细化不代表真实GIS或工程设计。玩家原深色连接线仍是既有端点间的示意路线，本轮不改它的拓扑或路径；外送导线用银铝色明确区分。没有验证真实GPU、跨平台打包或完整实鼠标连线建造流程，后者由现有控制器/调度测试覆盖。旧材质Image.load_from_file的导出警告仍存在于基线，不在本轮扩大修复范围。本增量保持版本号 1.0.0.2，通过同一仓库的普通增量提交管理，不创建 tag 或 release。


## 公开源码与复现

公开整理没有重新执行测试，只保留已验收源文件、运行所需颜色图、生成器及可读验证范围；没有发布运行截图、遥测、性能采样或玩家存档。

按根 README 导入 Godot 项目后，可分别运行 `tests/test_world_infrastructure_1002.gd`、`tests/test_export_corridor_visual_1002.gd` 和上述专项测试；固定聚合入口为 `bash tests/run_all.sh`。可选原生捕获脚本是 `tests/capture_world_infrastructure_1002.gd` 与 `tests/capture_world_review_1002.gd`。需要时先创建本地 `evidence/world_infrastructure_1002/` 输出目录；捕获文件会被现有忽略规则排除，但任何未来发布前仍应审查。

地表颜色图已随仓库提供，正常运行不需要重新生成。重建工具 `tools/build_landscape_detail.py` 使用 Python 的 NumPy、SciPy 与 Pillow；它只从已有颜色图生成细化颜色，不改高度或控制权重。这是额外建模工具依赖，不是打开游戏的必要依赖。
