# 选中设备运行曲线：数据契约与开销边界

`device_runtime_chart.gd` 是纯显示组件，不求解、不写设备参数/库存，也不写存档。`world_game.gd` 仅在 `advance` 中实际提交库存与模拟时间后把该步报告交给组件；`refresh`、优化预测和暂停检查不增加点。

- 只记录当前选中设备。未运行、没有真实提交步、取消选择、对象失效、空间不足时不显示空窗。暂停隐藏；恢复可继续本对象短历史。切换对象立即清空，不能把前一设备曲线嫁接到后一设备。
- 真正固定容量240点环形数组，按模拟时间排序，不用无界限追加。采样至少相隔1模拟秒且200ms墙钟时间，界面最多4次/秒重绘；高速运行会抽样，横轴保留真实模拟时间。图标/设备详情和参数动作不产生伪造点。
- 风机/光伏用实际送出 `sent_mw`，不把未被下游接纳的 `generated_mw`/可用出力画成实际出力。
- 电储能画实际充/放功率MW，热储能画MWth；SOC从本步提交后真实库存/容量计算，用单独0–100%下图区，不与功率共用轴。氢系统SOC是LHV库存比例，不称作可直接输出的电量。
- 其他设备依真实报告字段画送热、供能、泵电耗、排热或汽轮机毛发电，图例明确口径。一级电热站只汇总最终换热器实际供热；塔站只汇总汽轮机毛出力，不把毛出力说成扣辅机后的净外送。无物理能力的塔站预览不画图。
- checkpoint和restore清空短历史，覆盖编辑、建造/拆除、导入、示例替换、撤销和旧存档加载；时间回退也触发防护。此历史不跨场景、不占存档、不是运行数据导出功能。
- 弹窗、设备建造浮层、地图图层展开时隐藏图表，避免叠遮。左上避让顶部HUD和视角栏，窄屏动态高度最小170px；不足时隐藏，不压坏控件。

验证：`test_device_runtime_chart_1003.gd` 81项，包括固定缓冲、双时钟限频、全27类真实dispatch字段、缺数据/非法数据不造零点、SOC单位、窄高绘制、暂停/换选；`test_runtime_chart_world_1003.gd` 19项，在真实世界控制器中放置/接线/充电并验证只在库存提交后采样、预测无点、恢复清空。实际桌面曲线的最终视觉验收仍待协调窗口交接，不能将上述测试称作人工视觉验收。
