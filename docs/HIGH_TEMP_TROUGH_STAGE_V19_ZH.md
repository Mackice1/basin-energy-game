# V19 槽式高温光热供热与储热

2026-10-16。此阶段加入预热完成后的 Therminol 66 导热油 300/200°C 固定温区运行链。当前存档 schema 10 / model 19，读取旧 schema 3–9；新增设备优化快照 schema 4，无新增设备仍保持旧快照和计算结果。

## 运行链与操作

站内新增槽式集热器、高温双罐储热、油水隔离换热器。槽式可直接向油水换热器供热，也可向高温储热充热；储热向油水换热器放热。油水换热器输出 90/60°C 一次热水，再经原有隔离换热器向 70/40°C 热负荷供热。每一级换热损失独立扣除一次。油水换热器不能直接向二次热负荷连线，热水设备不能给高温油回路充热。

在米制站内选择高温光热示例可建立匹配的小热负荷演示。原有设备、默认负荷和示例不替换。设备参数沿用后台、保存、撤销、导入、优化面板。场内净区仍48×48m，大容量设备必须真实占地并通过空间检查；不能放下时拒绝，而非缩模型。旧示意尺度场景须先显式米制迁移。

## DNI 与太阳跟踪

槽式只使用独立 `dni_wm2`（直接法向辐照），旧真空管仍使用 `irradiance_wm2`（其固定集热面的 POA）。不把 POA、GHI 或 DHI 换名作 DNI。CSV 导入字段为全局 DNI，明确支持 W/m² 或 kW/m²，范围0–2000W/m²；与 POA/GHI/DHI 等明显相冲突的列名拒绝映射。通用列名选择 DNI 是用户声明其物理口径，并不代表软件已验证气象测量。

没有有效 DNI CSV 时，仅含槽式设备的场景生成独立教学 DNI：950×(0.35+0.65√sin太阳高度角)×(1−0.95云量)，夜间为0。这是教学天气假设，并非由 POA 反演，也不是气象预报；界面显示教学/CSV来源。CSV仅导入POA或其他天气时，DNI仍标教学。优化和实时均使用同一采样快照。无 DNI 的直接物理/求解输入拒绝计算；即使矛盾CSV给出夜间正DNI，夜间仍不集热。

槽式为南北水平轴单轴跟踪，太阳方位角从北顺时针。cosθ=√(1−(cos高度角×cos方位角)²)，太阳落到地平线以下停机向上收拢；实际几何法线随同一太阳位置旋转。IAM取1；端损、阴影、风致停机及动态接收器温度未解析。

## 集热物理与功率

单教学镜段长12m、孔口宽5.77m，孔口面积69.24m²。默认一个镜段，非兆瓦级虚拟设备。Q油=A×max(0,ηDNIcosθ−a1ΔT−a2ΔT²)/10⁶ MWth；ΔT=max(0,250−环境温度)，固定油平均温度250°C。

默认 η=0.75，a1=0.10 W/(m²K)，a2=0.0002 W/(m²K²)，均为明确教学等效系数，不是厂家或 SAM 拟合性能。20°C、DNI800、cosθ=1时单段可利用热39.2189208kWth。光学未截获、集热热损、可利用热、实际采集、未采集热分别列账。需求为零、储满、断接或缺电时安全停泵/弃集；真实接收器仍可能吸热，实际工程需离焦、过热保护和工质安全设计，本版不求停滞温度。

集热场泵与跟踪辅机为实际采集油热的2%；油水换热器独立循环泵为其输入油热的1%。两者同时受真实电源、站级与共用线路容量约束。夜间储热放热仍需油水换热器泵电；无泵电不放热。储热充热循环包含在集热场辅机中，不重复收费；固定待机电及启停二进制泵耗未模拟。辅机电能独立计耗，不虚加到油热。

## 双罐与固定温区边界

默认可用容量0.2MWhth、充/放功率0.1MWth、充/放效率各0.98、自放率0.005/h、初始SOC0。自放为 E×exp(−λdt) 的可用能衰减，是教学假设，不是罐体UA动态。SOC只表示200→300°C的可用焓差；SOC0意味着预热完成的200°C冷油，绝非室温冷启动。初次预热、冷罐底能、200°C保温、膨胀/液位动态、流量及温度动态不在本阶段。

Therminol66资料200/300°C比焓394/632kJ/kg，差238；300°C密度809kg/m³。每1MWhth需15126kg可转移油，热态体积18.697m³。每一只罐均容纳全部库存，20%空置率下每罐几何容积23.372m³，H=D约3.099m。不能把双罐总容积折半，也不能将两只罐重复计为双倍能量。默认0.2MWhth按同一公式缩放。

油水换热器默认输入能力0.1MWth、传热效率0.98、最小端差10K；油300→200与水60→90逆流端差210/140K，参数不能允许低温倒供高温。2%损失显式列账。连接端口同时检查工质、温区、方向及允许设备组合。

## 几何、面积与土地

原始Blender/GLB与程序几何使用相同米制。镜段抛物线焦距1.71m、轴高3.5m、保守全角扫掠半径3.25m；模块扫掠与端管包络6.5×13m，最大高6.75m，另有2m边界检修区和2m模块间隙。不足一整段的请求孔口仍占完整镜段，不能压缩实际占地。检修距离为教学布局假设，并非认证安全间距。储罐按每罐完整热态库存连续计算，油水换热撬默认3×2×1.8m/0.1MWth为教学几何。详见 art_source/blender/HIGH_TEMP_GEOMETRY.md；可编辑源 high_temp_assets.blend。

## 守恒与优化

独立油账：实际集热+储热放热=储热充热+水侧输出+油水换热损失。库存另计充放效率与自放。既有水热账仅收到油水换热输出；所有电辅机纳入原有AC网络。独立审计从原始天气、边流、设备参数和库存重建，不依赖汇总字段自证。GLPK 使用同一物理上界与损失、分别约束两组辅机、库存和终端SOC，禁止同罐同时充放。
