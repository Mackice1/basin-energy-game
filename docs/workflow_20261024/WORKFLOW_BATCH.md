# 1.0.0.4：建造流程与风光储氢入门

## 本批功能

- 建造时工具栏明确显示“连续建造 / 单次建造”。连续模式成功放置后继续同类，单次模式成功后返回选择；非法位置不提交、不退出当前预览。
- 建造、连线、移动工具统一右键退出，清空预览和待连接起点；取消不删除已建设备或线路，不改变库存。本次取消按压不会同时转镜头，松开后普通选择模式的右键拖动仍转视角。
- 连线提示区分选择起点和选择终点，保留类型、方向、温区及容量校验。
- Esc 保留分层关闭行为，模态窗口不透传到背后工具。
- 不新增设备旋转模型。当前设备朝向按既有规格固定；镜头旋转不是改变光伏方位角、风机偏航性能或设备工程布置。

## 入门入口

“场景”侧栏 → 模板与教学示例 → “入门：风光储氢外送与容量比较”。

入门面板载入一个八节点、九连接示例：风机、光伏、中压变配电、用电需求、锂电、有限供水、电解制氢、气态储氢，另接外部电网。它使用既有设备和模型，不增加设备类别。替换需确认，完整地形/间距/规格/存档验证通过后才提交，失败保留原场景，一次撤销可恢复。不会写入存档。

默认从2025-06-03北京时间17:59:30开始（真实小时边界前30秒，便于直接看到源值变化），累计产出为零，电池和氢库存为空，水初始10000 kg。气象为有来源的敦煌附近ERA5小时再分析，不是当地站点实测；GTI为服务商30°朝南平面的派生辐照，设备出力是现有模型计算。可回放June1零点至June8零点，小时内零阶保持，末端暂停、不循环或外推。真实初始时刻可制氢，未强行制造外送；运行消耗有限水、积累氢。打开面板暂不推进世界，关闭后按原运行状态继续。

面板显示当前实际模型流向，以及缺供/弃电/制氢状态。无产氢时只能报告可观测条件和待检查的电/水/氢/压缩连接，不从零产量断言唯一故障原因。

## 容量比较边界

- 隔离复制当前支持的设备、参数与线路，改变锂电容量为0.5×、1×、2×，充放功率不变。
- 每个方案电池/储氢均为空，供水按参数初始量重置。既有运行库存和历史累计不作为比较投入，也不写回游戏。
- 每个容量方案先验证规格及全体电池同时扩容后的原地布局；无法放下则不计算，不自动搬迁。
- 相同2025-06-01 00:00至06-02 00:00（UTC+8）24小时历史气象、300秒离散步长，分批运行可取消；并非全7天。它不是实时1秒积分，不是预测、经济优化或工程容量认证。300秒与60秒检查只适用于本例，不泛化到任意场景；容量增大不一定降低缺供，可能仅增加期末库存并减少外送/制氢。
- 指标来自既有调度：负荷实供/缺供、外送、弃电、产氢、用水和期末库存。成本未建模，明确显示“未建模”，不填零或排名。
- 固定调度顺序为负荷→电池充电→制氢→外送；电池仅补负荷，不为电解槽供电，也不放电外送。储氢压缩耗电已计入。

### 运行曲线口径修正

升压站及集电站的 `sent_mw` 含站端流向负荷、储能、制氢等所有受端的送出，不能称为外送电网。曲线现分别显示“站端总送出”（`sent_mw`）和“电网净接收”（`delivered_mw`），单位 MW。兼容缺字段报告时只显示真实存在的系列，不用另一字段替代或补零；采样仍仅来自已提交的实际运行步，未改调度、物理或历史。新回归采用实际多受端示例验证两值不同，及缺失、非法和非有限报告。

### 有来源的小时回放

源数据与归属见 `data/weather/dunhuang_era5_metadata.json`。100m风速通过已有0.14幂律换算至受现有布局支持的90m轮毂，属于模型假设；PV冷却使用10m风速，空气密度由地面压力hPa×100和温度计算。日历为UTC+8、网格40.25N/94.75E；不重复偏移时区。

示例专用加速回放每帧最多30次现有1秒提交，约25ms工作预算（单步结束才检查，允许一小步超出）；不跳过电池、水、氢库存积分，不承诺固定倍率。普通暂停可停，调整1–60倍速退出专用回放，替换/还原场景清除此临时模式；不写入存档。数据每小时变化，曲线旁显示当地时间及小时阶梯，并不生成虚假的秒级风噪。

演示起点选择真实序列中相邻小时模型风电可用功率变化最大的边界前30秒：2025-06-03 18:00，源100m风9.73→12.22m/s。选择的是演示片段，不是对整周波动的统计概括。载入仍确认替换并重置空库存/累计账，不跳已有运行状态；曲线取实际提交后的送出，可能与可用发电不同。跨界后可改普通1倍保持观测，暂停会按既有规则隐藏运行曲线。
