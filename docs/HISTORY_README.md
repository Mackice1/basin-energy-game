## 快速运行

1. 安装官方 Godot 4.6.3 Standard，不需要 .NET。
2. 解压完整工程；保留 `addons/`、`assets/`、`generated/`、`config/`、`scripts/` 和测试文件。不要只复制单个脚本。
3. 在 Godot 中导入 `project.godot`。首次资源导入完成后，完全退出并重新打开编辑器，避免 Asset Placer 首次脚本重载问题。
4. 按 F5 启动。当前入口为 `main.tscn` → `scripts/world_game.gd`；该控制器继承 V2 地形脚本。
5. 正常启动为空设备场景。地图上的边界公用设施标记是外部接口，不是已建电厂。

命令行：

```sh
godot --headless --editor --path . --import --quit
godot --path .
```

如果受限运行环境不能写 Godot 用户数据目录，可临时把 `HOME`、`XDG_DATA_HOME`、`XDG_CACHE_HOME` 指向可写目录。修改这些路径也会改变存档位置；恢复原路径后不会自动找到另一位置的存档。

项目携带 Terrain3D 与 Asset Placer 源文件/桌面平台二进制。插件版本、许可、原始地形生成方法和 V2 历史测试记录见 [保留的 V2 README](V2_README.md)。该文件是历史说明，不是当前重建功能验收报告。

## 操作流程

### 观察与建设

- 右键拖动旋转；中键拖动平移；滚轮缩放；W/A/S/D 平移。
- F1/F2/F3 切换视角，R 重置；数字 1–8 或左侧按钮切换地图覆盖层。
- 底部建造栏包含“风机 / 光伏 / 变电站 / 电池 / 电热站”；锅炉、储热与换热器在站内建设。用电需求通过右侧“用电需求”设置外部需求接入点，不属于可建设备。绿色预览表示当前初筛可建，红色表示不符合场地、坡度或间距约束。
- 在地面左键放置；可以连续建造；Esc 退出建设模式。
- “选择”模式点击设备电端口附近选中。“移动”后点击新地块；不合法的移动会被拒绝。
- “拆除”需要确认，会同时移除关联线路和绑定数据。Ctrl+Z 或“撤销”恢复最近的场景修改；最多保留 40 个内存快照，撤销后暂停模拟。没有重做功能。

米制占地初筛由 `spatial_dimensions.gd` 统一计算：根据真实参考模块数、安装矩形及检修边带生成保守外接圆；实体投影、土地面积、避让圆和风机转子包络分开计量。修改容量引起模块增量时重新验场地，不能通过缩小外形塞入。旧档继续保留旧示意半径。地形检查是有限采样初筛，不代表基础工程、叶片净空、消防或真实地形施工验收。

### 接线与运行（源网荷储基础）

1. 建风机/光伏、变电站，可加电池储能站；通过“用电需求”添加需求接入点。
2. “连接”后依次点击两端端口。风光→变电站；变电站→负荷；电池与变电站只需一条双向电缆。反向点击顺序会规范化。
3. 外部电网是可选出口：选变电站后展开“技术详情”并连接外网。全场仅接收不超过4 MW，不进口、不兜底缺供。
4. “出线”打开所选设备的关联线路清单，逐条修改发送侧容量/损耗或断线；每次修改可撤销。
5. “运行”使用1–60倍滑条（每次1倍）和右侧整数输入框双向同步，可独立暂停；读档与撤销后暂停且恢复×1。实时显示负荷实供/缺供、实际发电、弃电、网络损耗；展开分项看充放电、储能内部损耗与守恒差。电池选中后显示当前MWh与SOC。

本轮为固定优先级、确定性的有功容量流教学模型，不是交流潮流或经济最优求解。每个非站设备最多接一座站，站可分多路；站间、环网、多站共享设备尚未开放。端口校验载体electricity_ac、MW、AC_BUS电压标签、方向、存在性与重复连接。未接线电源全部弃电，未接线负荷全部缺供；电池孤立时仅计配置的自放电，不参与供能。

同一网络先用可再生满足负荷（priority小者先，同级按稳定ID），缺口可调用电池，余电依次充电、外送，最后弃电。电池不为外送放电，不给另一电池充电，同一步不同时充放；各线路与站容量、损耗统一扣一次。电池AC端充放功率MW与库存MWh严格区分：Enew=E×exp(−λ×dt_h)+(ηch×Pch−Pdis/ηdis)×dt_h。初始SOC只用于新建；改初始比例不能重置已存电量，容量改小于现有库存会拒绝。

“场景与存档”有原4 MW外送示例和新“源网荷储示例”，替换前确认且可撤销。命令行 --storage-demo 可启动新示例。初始电池5/10 MWh是明示的教学初值。

“导出优化快照（未求解）”把当前拓扑/参数/状态/约束写到Godot用户目录 optimization_snapshot.json；预留GLPK优先评估的独立后端接口。V13另提供“GLPK 运行优化与时序图”，调用真实GLPK；分析结果与实时态分开，不自动应用。实时与快照共用设备目录、端口与储能限值。EnergyScope借鉴边界及后续热/氢设备设计见 docs/ENERGY_DEVICE_CONNECTION_SPEC_ZH.md；未实现设备不出现在建造菜单。

## 设备参数表单

右侧“参数”只修改选中的设备；“新建设备模板”只影响以后新建设备，不反向修改现有设备。点击右侧“参数”打开中文数值表单，按名称、数值、单位和允许范围对照编辑，再点击“校验并应用”；取消不提交。非法文本、非有限数值、越界值和不相容的风机规格会被拒绝。未知字段仍由底层校验拒绝；缺省字段采用模型默认值。当前风机表单已补充参考空气密度和自定义电功率曲线；编辑与校验边界见下方“后期界面与地图视觉修订”。

小数比例不是百分数：例如 2% 损耗填写 `0.02`，不能填写 `2`。

## CSV：设备实测功率或气象

完整格式和示例见 [CSV_IMPORT.md](CSV_IMPORT.md)。基本操作：

1. 点击“导入 CSV”，选择 UTF-8 文件。
2. 选择功率、风速、辐照或环境温度，绑定设备或全局气象。
3. 明确指定时间列、数值列、时间单位和数值单位。
4. 预览转换后的数值、范围与来源；通过后再应用。取消和失败预览不提交数据。
5. “数据来源”可检查或移除已绑定的数据集。

支持逗号、分号、制表符；每次导入一个数值字段。单文件最多 8 MiB、100,000 数据行。列名必须唯一；缺值、非数、重复或倒序时间等被拒绝，不自动清洗或补值。

- 功率：kW / MW，绑定单台发电设备；传入物理模型时统一换算成 MW。
- 风速：m/s / km/h；辐照：W/m² / kW/m²；温度：°C / K。
- 时间：秒、分、小时，或带 `Z` / `+00:00` 的 UTC ISO 时间。
- 辐照输入是组件平面辐照 POA，不是直接把 GHI 当 POA。当前界面没有测量风高映射，不能自动把不同测量高度的风速修正成轮毂风速。界面明确尚未读取 `wind_height_m`；PV冷却复用相应风速为教学假设。设备专属气象仅影响绑定设备，不代表全局实景天气；未绑定出力字段仍用教学值，未导入云雨则其状态未知。

每台设备采用 **直接功率 > 适用的设备专属气象 > 全局气象 > 未绑定字段的内置天气**。直接功率包括有效的零值，会完整覆盖该设备的气象模型出力；不会把两份出力相加。最终出力仍经过设备额定上限和网络容量/损耗。

应用成功会替换同一目标、同一字段的数据，将模拟时间设为当前实际使用数据的共同有效区间起点，并清零累计电量；可以撤销。移除输入也会重新计算下层数据的有效区间、重设时间并清零累计量。如果候选输入没有共同的正时长区间，应用或移除操作会被原子拒绝，原场景保持不变。被更高优先级输入完全覆盖的数据不限制当前运行区间。

采样采用**左值保持**，不线性插值。时间区间保留 float64 数值；积分按不超过 1 秒并进一步在采样边界切段，正的亚微秒时段也会先计入。遇到实际使用序列的末端即暂停，不外推、不补零、不悄悄退回内置天气。最后一个样本在其时间点可读，但没有末端以后的积分时长；单样本数据不能独立形成可运行区间。

**ISO 对齐限制：每个文件各自把首条 UTC 时间设为 t=0，并保存原始起点。程序不会跨文件按绝对日期自动对齐。** 需要日历同步时，导入前先让所有文件使用相同首条 UTC 时刻，或自行转换成同一基准的相对秒数。

新导入功率受当时设备额定功率约束。若之后降低设备额定功率，原测量数据仍随存档保存，运行时由模型对超额部分削顶；不会篡改测量值。

## 三个本地存档槽

展开右侧“场景与存档”，选择槽 1、2 或 3，再点击保存或读取。覆盖保存、读取替换场景均需确认。读取前验证结构、数值、导入来源与拓扑，并按建设时的采样方式复检地形禁建和坡度；读取后暂停模拟，且读取操作本身可撤销。

存档包括设备与位置、线路、单台参数、未来建设模板、完整导入 CSV/映射/哈希/样本、当前时间、累计电量和线路显示模式。原 CSV 文件移走后，完整存档仍能独立保存输入数据。

## 本轮新增参数与状态

电负荷：demand_mw（请求MW）、priority（整数，小者先）。电池：capacity_mwh（MWh容量）、charge_mw/discharge_mw（AC端MW）、charge_efficiency/discharge_efficiency（0–1）、self_discharge_per_h（1/h）、initial_soc（新建初值比例）。默认电池10 MWh、3/3 MW、0.9/0.9效率、零自损、50%初始SOC均为教学假设。运行库存另存 device.state.energy_mwh，不由刷新、参数窗口、读取动作额外积分。

累计电量账：generated+discharge=delivered+curtailed+loss+served+charge。generated是可用发电，loss仅网络损耗；storage_loss单列内部转换/自损，避免从AC端守恒再次扣减。现有CSV仍只给风光直接出力或气象，不让负荷/电池被误当发电机绑定。
