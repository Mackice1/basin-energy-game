# V16.2 有边界界面优化

2026-10-16。承接 V16.1 / Library v9 已交付源码；开工前900个冻结文件全部SHA-256匹配。本轮仍为schema7/model16，米制、设备类别、库存、天气、能量积分与GLPK约束不变。

## 本轮四项完成条件

1. 站内建设与编辑分为两行可换行操作组，缩短取消按钮并保留完整提示。1024×768与1440×900下，按钮可见可点；嵌入弹窗按逻辑画布计算尺寸，避免物理窗口缩放被重复应用。
2. 右侧分“设备与运行”“连线与端口”两页，选中设备优先，淡色面板与文字对比清晰，内容可垂直滚动。连接模式自动切到连接页，取消/建设/选择回到设备页。起点、终点及悬停载体/温区/容量有明确文字。
3. 基地选中标题优先，屏幕空间碰撞时隐藏较低优先的悬停名称或多行次要状态，保留必需端口标识；不移动模型、端口或点击区域。右侧长指标名换行，数值与单位列保持对齐。
4. 基地连线提示用实际流向的设备名显示“来源→去向”，下一行给出AC/温区、容量、可连接或拒绝原因。两行摘要避免无限撑高，完整文字保留在悬停提示。

窗口尺寸变化会取消正在进行的拖动并清除预览，旧的松开事件不提交位置。UI操作与模拟时钟仍分离，未以缩小设备或降低物理采样换取帧率。

## 已知边界与停止点

这轮止于以上四项和回归，不继续无限打磨。固定1600×1000逻辑画布在小屏会整体缩放，1024下字体仍比1440小；没有承诺移动端或任意极窄窗口适配。极端自定义高塔仍使用占地为主的聚焦取景，可能裁切塔顶；默认参数设备专项通过。没有新增镜头平滑动画。3D次要状态仍参与深度遮挡，部分角度会被地形遮住，完整状态可在UI中查看；不宣称所有角度标注都无重叠。云llvmpipe仅是功能和同场景对照环境，不代表真实GPU表现，不能称流畅。
