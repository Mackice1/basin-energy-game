## 白色矩形环

- Terrain3D 的 256×256 纹理分配域并非实际可见地形。control.raw 在 x±100、z±70 之外为 hole；原外环错误从正方形±128开始，暴露浅灰世界背景。
- 只改 environment_visual.gd：外环第一圈连接原 200×140 可见地形矩形及同一 height_at 高度。后四圈150/205/290/430、材质、1024三角形预算不变。
- 无碰撞、拾取、资源产出、可建设地表、经济网格或位置变化。
- test_environment_visual_phase2：8,715项通过；1743散布实例、总近景53,677三角形，与前版相同。新增可见边界与128段接缝高度验证。

- equipment_visual.gd 的共用物质端口旧实现将所有非水物质显示为氢。已按真实 species_id 区分 H₂、H₂O、N₂、CO₂，不改变端口契约。
- test_chemical_visual_phase2：120项通过，含非氢端口不得写H₂；test_visual_annotation_camera：318项通过。
