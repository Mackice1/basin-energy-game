# 本轮模型的实际GUI核对清单

公开整理说明：本文保留研究或开发阶段记录；带时间的计数、计划与待验收状态仅适用于对应时点，不代表逐项人工验收已完成。最终范围见[最终原生验收](FINAL_NATIVE_ACCEPTANCE_1004.md)。原始运行日志、截图、玩家存档、备份与研究图像不随源码分发；下文非公开记录仅为来源说明。公开整理没有重新运行游戏或测试。

以下为历史GUI检查清单，不表示所有条目已执行。离屏结构图不替代Godot灯光验收；检查方法见[验收计划](FINAL_GUI_ACCEPTANCE_PLAN.md)，最终已执行范围见[最终原生验收](FINAL_NATIVE_ACCEPTANCE_1004.md)。

1. 新建液流：显示flow_process_v2，参考工艺单元六组双层箱体+独立PCS，单元工艺38×15m、含外围42×19m；当前默认容量、模块数与总占地按最终冻结共享规格和详情逐项核对，不继续套用旧20MWh默认文案。降额不缩已安装硬件。旧无标记存档仍原位置和小图标双罐，占地18×14m/旧单模块，显式标图标化，不自动升级；旧件端口与库存不变。
2. 钠离子：按本轮最终冻结合同应有3个真实电池箱体，灰白电池仓、独立冷却格栅、基脚和PCS可辨；PCS不是第3个电池箱，不要仅靠金黄色辨认。证据或实现未收口时本项保持待验，不能宣称通过。LAES：高绝热罐、真实梯/平台、冷箱/压缩机/膨胀机和热冷回收管路均可辨；不出现额外热网口。固体蓄热：钢框/斜撑/通道端盖、热供回管可辨，只有90/60热口，不能直接发电。
3. 气氮供料：多组立瓶、汇流/阀表，不是空分厂；气CO₂供料：大柔性囊+悬挂框架/管嘴，不是液体储罐。两者各仅一个真实气态输出，1000kg有限额，不自动补充。
4. 合成氨：生产房、高工艺框架、循环/分离、干冷器、电热柜、气态缓冲接管。合成甲醇：更高分离塔、有限小液罐/围堰。两者三个输入无产品/热输出口；产品满库停产，不可免费清空。
5. 两相态氢站：液氢球形真空外护壳仅用于液氢，独立冷箱/机房/气化器清楚；LaNi5床架+电热/冷却与气瓶库不同。小宿主新建参数显示相应派生容量，不能仍写固定10t/120kg。每类外接只有AC和气氢进出。
6. 汇集站：两主变三相接线→AIS间隔→母线有辨识度，控制楼电缆沟贴地；不凭外观标电压。旧中压单元不应被放大成新站。
7. 用同一详情灯光检查白罐/地板/厂房不过曝成同一白块；所有端口标签、返回/Esc单层关闭、相机边界与原选择视角由UI回归和实机共同核对。
8. 本轮外延已经纳入真实4×4km可建域，不再沿用“外环只是不可建背景”的旧断言。四向扩展地表连续可拾取，完整设备占地越过±200世界单位时拒绝；域外远山仅背景。稀疏荒草/灌木/石块不遮挡设备和道路，三资源设施仍仅外部边界提示，不新增免费产出。
9. 一级电热/塔站只显示真实已安装成员；增删移动与参数更新即时同步，塔/镜不重复。新双水罐贴地且一级/二级/详情一致；旧对象显式保留旧几何。1180与640宽检查参数窗口、单位不换行、滚动及固定按钮可达，按最终验收路线留原生截图。
