## 新补充：真实供料设施，不以液罐冒充气态库存

### N₂瓶组及计量汇流

Morris真实现场已能看到标记为N₂的绿色瓶组，适合作有限气氮供料边界外形。另实际查看[BOC官方供气册](https://www.boconline.co.uk/wcsstore/IE_BOC_Industrial_Ntl_Store/pdf/downloads/shielding-gas-brochure410_80125.pdf#page=28)第28页1300像素原页：上半为钢瓶肩/阀保护帽近照，下半说明钢瓶成组、共用出口及搬运方式。下半另述低温液体容器，不能混作气态N₂同款。此页未证明某组N₂的精确质量或安装净距。

拟画多组直立钢瓶框架、顶部汇流、调压/计量阀组、防撞柱和遮雨控制柜。若模型没有空分/净化，不出现空分冷箱或PSA生产标签。瓶组数必须随确认后的库存模块量增加，或明示画的是有限外部供气接收边界；不把小瓶组当可容纳任意kg的体积证明。

### CO₂真气态缓冲，可与化学供料相态一致

制造方 [Presenco气体缓冲容器页面](https://www.presenco.com/products/tarpaulins/gascontainers/) 明确柔性气囊可用于CO₂/沼气缓冲，通常悬挂在框架，页面只给起始容积5m³，未给每图精确长宽。以下两图已下载到临时目录并实际看像素，**不是游戏资产**：

- [5m³文件名原图](https://www.presenco.com/wp-content/uploads/2016/10/5m3-ballon.webp)：制造车间中的蓝色圆角长囊，有织物焊缝/褶皱，不是高压钢制球罐。
- [50m³文件名原图](https://www.presenco.com/wp-content/uploads/2020/09/50m3-graa-med-2-stk-studser.webp)：车间灰色圆角大囊，两根柔性管嘴、上方悬挂点清楚。50m³来自文件名，不能当作完整型式认证；图片本身不能证明充填介质、压力或许可最大容量。

这提供了“纯气态CO₂有限库存”的非低温视觉方向：柔性低压缓冲囊+支撑框架/罩棚+进出阀组、计量柜。不能接着画液化制冷机或液体罐，又不扣相变/保冷能耗。[Linde供气说明](https://www.linde-gas.com/products-and-services/supply-modes/bulk-supply)也明确大宗液态储存再气化是另一条边界；出气口为气态不等于罐内始终气态。

图形若需要很小占地但核心要求很大纯气库存，必须报告不匹配，不能仅用“示意”掩盖体积矛盾。气囊应选择与默认库存数量级相称的模块数量；密度/压强/真实体积未建模时，不显示压力或以气囊涨缩声称SOC就是实测体积。

## 待核心确认后才实施的字段

- 正式kind字符串、默认/上限kg库存、最大进出流率、反应产能、宿主材料质量是否固定。
- 每个真实端口的ID、方向、物种/相态、kg/s或MW单位；无端口的内部公用工程不能画成可连线接口。
- 有限N₂/CO₂库存究竟为实际站内储量还是有限外部已制备气源的接收额度。两者都能有限，但外观和文字不能混淆。
- 氨产品气态参考库存的容量数量级，不能由液氨3000加仑照片推导；如果未来改液氨，应同步完整热学合同后再换形态。
- 液氢选环境气化还是电热气化；对应气化器、排热/加热构件跟实际电热账一致。LaNi₅必须有可辨换热/电加热单元，不隐藏放氢热源。
