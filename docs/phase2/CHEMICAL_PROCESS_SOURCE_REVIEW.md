核查日期：2026-10-21。本文是本接续阶段的**研究与待实现契约**，不是实现清单、厂商性能保证或化工工程设计。只新增本文，不修改生产代码，不操作用户桌面，也不修改冻结的 1.0.0.3基线。

## 1. 结论与设施边界

可以将合成氨、二氧化碳加氢制甲醇各建成一个独立的生产整站。完整站包含内部压缩、循环、反应、分离、冷却、必要电加热/电蒸汽及有限产品缓冲；反应器和催化剂只是内部构件，不拆成一级可独立建造设备。

拟定最小边界：

- 外部氢源为现有气态储氢供料；N₂、CO₂来自**有限、已制备好的纯气供料库存**，不得凭空补充。氮气制备/空分、碳捕集/净化、上游制氢不在这两个生产站的电耗边界内。
- 生产站只消耗实际获得的AC电与实际交付的物料。内部电加热与辅机都占用AC容量，不隐含免费蒸汽，不向现有热网索取未记账热量。
- 氨的本轮最小热化学基准为 NH₃(g)，甲醇为 CH₃OH(l)，副产水为 H₂O(l)。所有物料按298.15 K参考态记焓，气体采用理想气体参考近似，不据此宣称模拟了实际工艺温压。
- 产品留在各站自己的有限缓冲内。缓冲满、任一原料不足、供电不足或关闭时，先缩小可执行产量，再原子提交全部物料/电/热变化；零可执行产量不得先扣料。没有产品外送能力就停产，不能隐形售出或删除产品。
- 排热与甲醇副产水进入明确的环境累计边界。排出的水不自动回到净水库存，不自动当作饮用水或可直接进电解槽的水。

这是一阶质量与能量守恒教学模型，不是动力学、气液平衡、压降、危险扩散或启停控制模型。对热力学可行的账本定义，不等于证明任意给定生产速率/能耗都能由现实设备达到。

## 2. 化学计量与分子量

### 合成氨

N₂(g) + 3 H₂(g) → 2 NH₃(g)

来源：[DOE，H2IQ Hour，2021-05-27，幻灯片第5页](https://www.energy.gov/sites/default/files/2021-05/052721-h2iqhour_0.pdf)。DOE列示反应与约−92.4 kJ的教学反应热；下面实际账本另统一采用所选NIST形成焓，不混用两组数值。

### 二氧化碳加氢制甲醇

CO₂(g) + 3 H₂(g) → CH₃OH(l) + H₂O(l)

此为整站净反应，不声称是单一步骤的反应器机理。不能以“氢+电”直接生成含碳甲醇；CO/CO₂中间反应、循环气与分离可在整站内折算，但不得删掉净碳源或副产水。

来源：[IRENA与Methanol Institute，2021，Renewable Methanol，第44、56、78页](https://www.irena.org/-/media/Files/IRENA/Agency/Publication/2021/Jan/IRENA_Innovation_Renewable_Methanol_2021.pdf)。其原料量与净反应一致；文中整站高转化率/选择性不等于单程反应100%转化。

### 与现工程一致的质量基准

现 `material_process_profiles_v1.json` 使用 H=1.008、O=15.999 kg/kmol。建议扩展时保持这两个值，采用同一套有限精度原子量 N=14.007、C=12.011；每个分子量由元素求和，不另从不同精度表抄入。

| 物种 | 原子组成 | 此教学基准的分子量 kg/kmol |
|---|---|---:|
| H₂ | H₂ | 2.016 |
| N₂ | N₂ | 28.014 |
| NH₃ | NH₃ | 17.031 |
| CO₂ | CO₂ | 44.009 |
| CH₃OH | CH₄O | 32.042 |
| H₂O | H₂O | 18.015 |

从上述数值自行计算，每生产1 kg NH₃消耗约0.17756 kg H₂与0.82244 kg N₂；每生产1 kg甲醇消耗约0.18875 kg H₂与1.37348 kg CO₂，同时生成约0.56223 kg水。界面可以四舍五入，计算应保存由原子量求出的完整比值。含水副产物的甲醇反应中，投入质量大于甲醇产品质量是正常现象，不能用“甲醇产量=全部进料质量”替代反应。

H、N、C、O分别守恒；只检查总质量不足以发现CO₂被误当N₂、或甲醇未扣碳源之类错误。

## 3. 参考态和形成焓：相态不能省略

参考温度298.15 K，标准压力1 bar。H₂(g)、N₂(g)、O₂(g)为元素参考态，形成焓取0；“形成焓为0”不是“没有可利用燃料能量”。[NIST参考态说明](https://cccbdb.nist.gov/refstatex.asp)

| 物种与相态 | 本轮选定 ΔfH°，kJ/mol | 来源及选择说明 |
|---|---:|---|
| NH₃(g) | −45.94 | [NIST氨气热化学](https://webbook.nist.gov/cgi/cbook.cgi?ID=C7664417&Mask=1)，CODATA所列−45.94±0.35；同页另一评述值−45.90，不混用。 |
| CO₂(g) | −393.51 | [NIST二氧化碳](https://webbook.nist.gov/cgi/cbook.cgi?ID=C124389&Mask=1&Units=SI)，CODATA所列−393.51±0.13。 |
| CH₃OH(l) | −238.4 | [NIST甲醇凝聚相条目](https://webbook.nist.gov/cgi/cbook.cgi?ID=C67561&Units=SI&Mask=3)，选择其Baroody与Carpenter 1972条目。该页有多个历史测值，本轮不是宣称此项为唯一最新推荐值。 |
| H₂O(l) | −285.830 | [NIST液态水](https://webbook.nist.gov/cgi/cbook.cgi?ID=C7732185&Mask=82&Units=SI)，与现工程一致。 |
| H₂O(g)，仅用于区分LHV/HHV | −241.826 | [NIST水蒸气](https://webbook.nist.gov/cgi/cbook.cgi?ID=C7732185&Mask=1)。本轮甲醇排水不采用此相态。 |

若存入JSON使用kJ/kmol，以上每个值乘1000，不可漏乘。任一参考态数据更换应版本化并重算所有反应热，不能只改显示。

按“产物形成焓之和减反应物形成焓之和”得到以下**自行计算**结果：

- 氨反应：ΔrH° = 2×(−45.94) = −91.88 kJ/反应进度mol，或每mol NH₃ −45.94 kJ。用上节质量基准，约0.74929 kWh热/kg NH₃。
- 甲醇反应：ΔrH° = −238.4−285.830−(−393.51) = −130.720 kJ/mol甲醇，约1.13323 kWh热/kg甲醇。

上述为所声明边界间的反应焓，**不是发电量、辅机耗电、可售蒸汽或最低电耗**。液态甲醇与液态副产水已经包含气态反应产物冷凝到所选参考态的能量差；不能在此之外再无条件加一份冷凝潜热。

重要相态限制：本轮氨只核实并选择气态参考产品。真实氨厂常有液氨分离和储运，但不能给液氨库存直接套−45.94。若实现低温/承压液氨，必须补充对应状态的显热/相变/压力近似、制冷实际电耗和必要静置热负荷，产品状态及能量账同步升级。在这之前应标“NH₃气态参考库存，不计算压力/液位”，不能标“冷冻液氨”。相同道理，供料CO₂若被画成液态供料罐，也不能悄悄仍按气态物流零相变处理。

## 4. 电、热边界：全链电耗不能重复计算

### 已核实的量级只用于辨别边界

| 来源 | 来源中的边界及量级 | 本工程能如何使用 |
|---|---|---|
| [IRENA Renewable Ammonia，2022，第66页](https://www.irena.org/-/media/Files/IRENA/Agency/Publication/2022/May/IRENA_Innovation_Outlook_Ammonia_2022.pdf) | 低温电解路线约36 GJ/t氨，其中制氢约33；制氮另有约0.3或0.6–0.9 GJ/t量级，合成环通常至少约2 GJ/t。 | 36 GJ/t=10 MWh/t是含制氢的总路线量级，不可全部塞进已收H₂的合成站。合成环2 GJ/t≈0.556 MWh/t也不是对本教学小站的保证值。 |

成套厂的公开能耗常有不同边界：毛/净AC、制氢是否在内、原料供压、精馏产品纯度、冷却/制冷、蒸汽进出、余热抵扣、启停和负荷率均会改变结果。本轮没有找到能直接校准本拟定“外购N₂/CO₂、气库供H₂、电加热、参考态出料”的小型整站保证参数。因此不能宣称任何待选默认值为某厂实测值。

### 不接外部热网的可行简化

建议采用下述**模型设计推导，不是来源给出的性能保证**：

1. 固定单位产品内部工艺加热需求 q_process（kWh热/kg）；该项代表内部升温、精馏再沸等综合负荷，不是跨站热输入。
2. 有限电加热/电蒸汽额定功率，电热效率 η_heater 在(0,1]；实际热电耗 e_heat=q_process/η_heater。
3. 另有正的单位产品AC辅机耗 e_aux，包含该边界内压缩、循环、分离和冷却耗电。总净AC需求 e_AC=e_aux+e_heat；如选择已包含电热的整站净电耗，不能再叠加一次e_heat。
4. 第一版不给反应热任何回收抵扣，反应热和电功最后均经内部冷却系统排至环境。所有进出物流归一到参考态，内部不积累热。这样温级不足不会被伪装成可用蒸汽。
5. 每步整体能量式为 Q_reject = E_AC − ξΔrH°。单位先统一；两条反应ΔrH°<0，因此排热为AC耗电加化学焓降低。内部q_process不能在这个全站式里再扣一次，也不能作为免费外部热收入。

例如设定任意明确标作教学假设的 e_AC=1 kWh/kg甲醇，则本轮参考态下排热应约2.13323 kWh热/kg，而不是1、1.13323或0.13323。该例仅用于检查代数，没有推荐其作为工程额定能耗。

“净外部热输入为零”不等于“内部没有热负荷”。未来若用反应热减少电加热，只能以受限热回收率及匹配温级扣减内部加热需求；低温冷凝热不能未经说明直接满足高温负荷。若将回收热外送，必须从环境排热中扣除并在真实接收端记账，不能一热两用。

这种静态模型还假定冷却能力足够或显式设有有限排热上限；如设置上限，则生产量须同时受其约束。简化瞬时启停、固定比耗、无待机电耗均应明示，不宣称具备实际工艺动态。若加入待机电力，停产时仅保留这项明确的用电及等量排热，不产生产品。

## 5. 守恒账与提交前限制

建议用非负反应进度ξ控制同一事务，而非分别独立扣库存：

- 氨：Δn_N2=−ξ，Δn_H2=−3ξ，Δn_NH3=+2ξ。
- 甲醇：Δn_CO2=−ξ，Δn_H2=−3ξ，Δn_MeOH=+ξ，Δn_H2O=+ξ；水离开站时进入环境物料账。

ξ必须同时受原料存量、供料管线和站内最大流量、气库出料能力、实际可供AC、站内加热/辅机容量、产品剩余容量以及可选冷却上限限制。任何输入存在NaN、负值、不兼容物种/相态，均不得由截断或默认补料“修复”。两个站争用同一气库/电源时必须共享资源预约，不能各自按全量可用资源计算。

每步、累计及保存/读档后均检查：

1. 物种与四元素账：期初+导入−期末−导出=0。有限N₂/CO₂供料罐若已属于全世界库存，罐→厂只是内部转移，不重复计为新世界输入。
2. 总质量账必须包含产品、副产水及所有已建模泄漏/排放。未模拟杂质/吹扫时明确理想纯料、无净吹扫；不能为了“效率”凭空抹去未转化物。
3. 参考态焓总账：H_initial + E_AC,in + Q_in + H_import − H_current − H_export − E_AC,out − Q_reject = 0。H按物种形成焓及明确的附加状态能计算。纯标准形成焓可以为负，不可按库存电量思路钳制为0。
4. 产品最大容量编辑不能抹去现有产品，存档不能只保存累计产量却不保存当前产品库存。新建生产站默认空产品缓冲，不免费预装产品。

现工程2A的累计恒等式把净制氢/燃料电池反应对应到液水HHV，并仅检查H/O。加入氨/醇后必须另加N/C、相应反应进度、产品与副产水，不能保持旧式却把生产氢消耗冒充燃料电池耗氢。LHV展示是燃烧参照的可利用能指标，不可与标准形成焓直接相加。若采用等价的元素基准平移保留正值能量展示，应同时平移所有库存和边界物流，并以同一组反应焓校验。

## 7. 实施验收门槛与尚未核实项

本文没有执行任何运行时、MILP、存档或GUI测试。以下是实施后应测试的门槛，不是本轮通过项：

- 断电、断H₂、断N₂、断CO₂、管线损耗、原料空、产品满、恰好装满、同一步共享氢库争用、容量缩小、重复提交、暂停与恢复，均不生成物料/能量。
- 按同一组原子量、形成焓、相态与电热参数，对运行时、优化器回放及累计存档独立重算四元素和焓残差；篡改任一产品量/碳源量/排水量/电耗均能检出。
- 若未来允许产品放出、使用或销售，需新增同等严格的接收边界与产品能量去向；本轮不把它悄悄当另一座储能电池。
- 尚未核实：针对所选小型整站边界的实际净AC保证值、内部工艺热需求/温级、电热与冷却设备尺寸、气态NH₃缓冲实际体积/压力、液氨方案的状态焓、产品纯度及待机/启停曲线。因此默认产能、容量、占地、比耗只能明确标为教学假设，不标厂商校准。

守恒能排除无碳制醇、无氮制氨、免费电热和消失的副产水；不能替代实际工艺设计、安全审查，也不能据CO₂被转入甲醇就声称永久封存或全生命周期零碳。
