# 变电设备身份与真实比例审阅

公开整理说明：本文保留研究或开发阶段记录；带时间的计数、计划与待验收状态仅适用于对应时点，不代表逐项人工验收已完成。最终范围见[最终原生验收](FINAL_NATIVE_ACCEPTANCE_1004.md)。原始运行日志、截图、玩家存档、备份与研究图像不随源码分发；下文非公开记录仅为来源说明。公开整理没有重新运行游戏或测试。

核查：2026-10-21。只读审阅当前代码及官方资料。本轮只写研究文档，不修改容量、端口、几何或冻结版本。

## 结论先行

当前目录名 `station` / “变电站”过于泛化。代码实际是**聚合有功容量节点，外观借用紧凑中压平台/变压器+开关柜**，不是已经建好的基地110/220kV汇集升压站。默认4 MW、损耗1%，不是0.8 MW。不能把现有小柜整体放大后声称成为高压升压站，也不能仅因用户希望更真实而擅增额定容量或电压。

### 当前源码与无界面实测

- `device_catalog.gd::defaults("station")`：`capacity_mw=4.0`、`loss_fraction=0.01`。
- `Catalog.ports`：只有`in`输入、`out`输出；载体`electricity_ac`、单位MW、逻辑电压标签`AC_BUS`。没有数值电压、无功、变比、故障电流或保护模型。
- `spatial_dimensions.gd::profile`：每2 MW一个完整等尺寸平台，默认两个；单模块长×宽×高6.813×5.538×2.941m。默认组包络15.626×5.538×2.941m，四周教学余量2m后的安装区19.626×9.538m≈187.19m²；平台投影合计75.46m²。模块间2m，非厂家完整净距认证。
- 大地图米制换算0.1 world/m，两个平台保留相同实物尺度，合批后无新增调度节点。当前部件为油箱、散热片、套管、三柜门开关柜，**并未复刻SMA完整产品的两台逆变器**。
- `device_inspector.gd`专用 `station_detail_sample.gd` 仅展示一个代表性变压器/开关柜组合，不展示全站数量。独立详情局部坐标以米建模，实测AABB长×宽×高6.190×2.780×2.855m；与大地图平台不同是代表对象不同，不应以屏幕像素判定两个视图的米制相同或故障缩放。详情文字已说明非全站数量、非厂家CAD。
- 详情模型不参与放置/碰撞/求解，无电气端口API。现有真实端口、容量损耗和连线归原设备所有。

本轮以隔离HOME运行临时headless脚本读取默认值、profile、端口及详情AABB；未读取/写入用户存档，未操作GUI。

## 不改变既有能力的外观方案

### 立即可做：明确当前设备身份、提高紧凑设备真实性

1. 展示名称建议“中压变配电单元（聚合）”，保留kind、4MW/1%、in/out及存档兼容。名称变更由UI/物理负责人确认；本轮未直接修改。
2. 大地图继续画两个真实尺度模块，不增加高压母线场。按已核实现场结构补钢框架/支墩、服务平台、变压器散热片、三相套管、电缆端子、防护网与开关柜门缝/通风细节；实际零件数需批处理，远景只保留轮廓。
3. 因参考SMA包含逆变器而现有station不承担逆变，不能照抄整机并让玩家误以为获得逆变容量。可保留“变压器+开关柜原创教学组合”身份，SMA仅作平台尺寸来源；或另选同级无逆变器成套变电单元的新尺寸依据，再做显式占地迁移。不能混称OEM复刻。
4. 二级页建议增加“代表单元/全站布局”明确切换或全站布局示意；代表单元标米制尺和单元数量，不把一个6.19m样机说成4MW全站。通过相机放大细节，不通过拉伸几何改变长宽高关系。若改为真正共享米制全站模型，必须保留当前详情接口、相机边界和选择返回语义。

### 独立后续：基地汇集升压站

若产品需要110/220kV集电站，应建立新的明确设施类型/展示配置：主变区、AIS或GIS开关区、控制楼、避雷、防护与检修道、分开的集电与送出侧。使用实际项目批准总图与对应设备尺寸，不把现有小柜放大10倍。

可先在**不改端口的展示规划**里将现有聚合in/out映射为集电侧/送出侧，但绝不标注已模拟110kV潮流/保护；真实电压、无功、母线拓扑、变压器数量、容量档位和占地变化，需要与物理/存档契约一起评审。当前187m²紧凑组不能无提示改成几千平方米，旧位置/线路不能被挤占或自动重排。

## 大地图与二级物理比例的验收标准

- 地图远景允许图标、轮廓、LOD和屏幕拾取容差放大；实体包络、安装区、容量模块数不变。图标要明确是图标，不伪装等比例实体。
- 二级页可切代表样机或全站，不混用；尺寸标签分别给单元、平台、设备组和安装区，不能把平台深度当柜体深度。
- 单元数量随容量档位变化，不随功率直接同比拉伸每台变压器。
- 新外形不得新增电气功率、效率、端口、运行状态或暗中逆变器；材质改动避免详情灯光下过曝。
- 如需改占地，先列旧/新包络与既有设施冲突，再显式迁移；本研究没有批准静默改变布局。

## 2026-10-21 接续：旧中压单元外观已实现，合同不变

旧 `station` 保留4MW/1%、in/out与原米制面积。一级不再单独生成简化方箱，而与二级代表样本共用原创变压器/开关柜组件。新增抬高钢梁框架、混凝土支墩、两侧服务平台、支撑斜撑和显式细杆网围；原散热片、三相瓷套、油枕、绝缘引线、柜门/继保窗保留。没有额外逆变器、HV间隔、逻辑电压或新端口。重新查看SMA后继实拍确认框架/网围语言，不声称复刻SMA型号。

单样本实际几何6.80×5.52×2.90m，仍落在原单元6.813×5.538×2.941m包络；原单元/默认两模块/总安装区均未变化。二级代表样本新增了原本未画出的完整平台边缘，所以其可见AABB较原6.19×2.78×2.855m零件组合变大，但物理占地并未扩大，也不把一个代表样本当整个4MW站。默认两模块均完整绘制；超过16模块仅抽取均匀分布的代表实例，全模块数量和用地不缩小。每模块18,456三角形，9个共用材质批次。

专测 `test_station_visual_phase2.gd` 18项通过，旧 `test_station_detail_sample.gd` 通过。两张非公开结构核查图（未随源码分发）已实际查看像素；它们是Godot几何导出后Blender后台CPU渲染的结构核对图，**不是Godot实际灯光/材质或GUI验收**。全过程无Xorg、虚拟显示或GUI操作。
