# 源网荷储 V12 验收

2026-10-15。基于上一版重建，不是找回V10。设计见 ENERGY_DEVICE_CONNECTION_SPEC_ZH.md。

## 交付范围
- 统一设备目录和电载体端口；风光、变电站、电负荷、电池五类可建造。
- 真实连通路径、发送侧线路容量、接收侧站容量与各自损耗；孤岛、缺供、弃电。
- 固定优先级调度：负荷、充电、有限出口；储能只填负荷缺口，不为出口放电。非经济最优。
- AC端MW与库存MWh分开；有限步长、SOC、满空边界、充放互斥、转换/自损账。
- 三存档槽不变，schema4/model12写入，schema3/model11可读并补字段；库存与撤销一并保存。
- 只导出优化快照；设备/端口/容量/限值与实时共用。未安装/未调用GLPK或HiGHS。
- Blender风机、光伏GLB实际接入Godot。可编辑源位于art_source/blender，.gdignore阻止编辑器重复导入.blend；运行资产在assets/models。默认参考尺寸用GLB，修改风机尺寸则回退可参数化程序模型。

## 自动检查
最终回归详情以foundation/REGRESSION_FINAL.txt为准。模型、CSV、存档、控制器、参数、程序几何与GLB逐顶点检查分开记录；检查数不是独立用户用例数。

独立审计另外验证1,000个随机多岛网络76,791条断言，包括跨度0至1e8秒的步长、容量/损耗/库存/互斥、输入不可变和排序确定性。它是临时独立审查，不替代随源码提供的固定种子回归。

## 边界
- 仅一站一叶的径向容量流；站间、环网、交流潮流、负荷CSV、热氢设备、经济优化尚未开放。
- 所有新设备默认值是教学假设。电池初始电量明示，不代表免费随时补能。
- 资源纹理由V2原实现Image.load_from_file读取，Godot提醒独立导出需另做导入方式修复；本轮交付可导入运行的完整源码，不宣称正式可执行包。
- 本地保存原子替换不等于已完成断电/磁盘满容错验收。
