## 功能与边界

- 基地汇集升压站与中压变配电共用Catalog.is_electric_station判定。选中设备卡直接提供外网连接按钮，不再藏在技术详情；按钮明确使用当前选中站而非旧连线起点，非站禁用。端口、容量与撤销仍走原建造控制器，不自动修改既有连接。
- 只读拓扑提示覆盖无交流线路、缺输入、缺负荷/储能/外网出口，以及负荷上游站未接电源。电储能按双向拓扑识别。不猜测夜间、风速或零出力原因，不改变调度。
- 脏场景关闭默认取消，Esc也取消；“前往保存”仅打开现有存档卡，不写槽且不会排队自动退出。明确放弃才退出，显式保存失败后仍保护；清洁场景直接关闭。关闭决策显示时暂停后台推进，重复关闭不能绕过。
