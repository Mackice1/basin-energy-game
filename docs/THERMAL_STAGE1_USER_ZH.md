# 首批电热链使用与边界

本阶段在天气版上增加电热水锅炉、双温区等效储热和隔离换热器。用热需求位于右侧「用电 / 用热需求」，与用电需求一样属于外部任务接入标记，不是建造设备。模板面板可确认覆盖后应用「电热完整链示例」，支持撤销；示例热储初始为空。

## 端口与单位

- 变电站 AC 电输出 → 锅炉 AC 电输入（MW）。锅炉电输入为真实内部用电，不能同时再当外部负荷重复计入。
- 锅炉热出口 → 换热器热端或储热入口，储热出口 → 换热器热端：90/60°C 主温区，MWth。
- 换热器次温区出口 → 热需求：70/40°C，MWth。
- 连线支持反向点击自动确定方向；不匹配的载体、端口、温区、重复边会拒绝。选「出线」可改热输送容量或断线，热线路损失本批固定为0；换热器散失单独计算。
- 电池库存为 MWh，热储库存为 MWhth，不能互换。SOC仅为可用库存比例，不代表罐温。

锅炉默认额定电输入2 MW、效率0.98；换热器默认热侧容量2 MWth、效率0.98、最小端温差5 K；固定温区两端温差均20 K。锅炉只有下游接纳时才消耗电，没有虚构弃热汇。默认热储4 MWhth，充/放各2 MWth，效率各0.98，自损0.002/h。固定品质等效模型不模拟水量、压力、泵管回路或温度混合，循环辅机与转换散失包含在等效效率假设中。

## 实时运行与库存

所有电热设备使用同一模拟时钟、已有天气与出力CSV。直接导入可用出力仍优先，热需求本批为独立常量 MWth，不支持热需求CSV；电负荷倍率不缩放热需求。

热储采用 E新 = E旧 × exp(-λΔt) + (η充 × Q充 - Q放/η放) × Δt；每步严格不同时充放。孤岛仍自损，暂停不推进库存。初始SOC只用于新建，修改参数不重置存量；容量低于现有库存会拒绝。存档与撤销含设备、热库存和累计热账本；恢复后暂停、倍速回到1。

实际运行按电热需求priority和稳定ID分配：热需求先由可再生电驱锅炉直供，再用热储补缺，最后可调用电池驱动锅炉；余可再生先充热储再充电池及外送。此规则避免恒定盈余时无谓充放热循环，但不预知未来。

实际运行是确定性规则调度，分析面板则是真实联合电热GLPK前瞻优化。两者都遵守相同设备系数、边界、线路限制和载体守恒，但预测调度策略可以不同，不能把实时基准称为最优。

## 优化分析

分析冻结当前已建设备容量、连线、库存、天气配置和数据来源，不新增设备，也不把分析状态写回实时地图。每时段锅炉电耗与出热由同一活动量耦合，热储含独立二进制充放互斥。目标依次最小化加权电热缺供、最大化外送、最小化存储吞吐、最小化热活动。电与热缺供均按各自能量积分，热服务权重显式可设，不能把 MW 与 MWth 的图线混成一个物理载体。

可配置独立期末热SOC下限；严格供给同时约束电和热。不可行、取消、超时、可行非最优和失败均保留真实状态。结果显示独立热功率、热SOC和库存图、时刻详情、设备详情及基准比较；所有图来自真实求解结果。原始决策另行审计电、热、库存与转换关系，审计失败不展示成有效方案。
