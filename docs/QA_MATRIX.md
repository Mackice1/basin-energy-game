## 状态如何理解

- **GUI 已验**：本轮确实进行了相应鼠标/键盘交互并观察结果。
- **自动测试已验**：对应代码路径在自动化测试中运行通过；只覆盖该测试明确检查的条件。
- **待验**：有实现或测试计划，但尚无相应验证记录。
- **未实现 / 范围外**：不得因列入清单就暗示已经支持。

大量断言可能来自顶点、风速或随机网络循环，**不能换算为功能数量或替代验收清单**。测试中的“守恒”只证明简化模型与积分的内部一致性，不代表真实设备校准正确。

### 已修复的独立审计问题

1. 共同区间使用浮点数值字段，避免 `Vector2` 的单精度造成 10.2 秒起点漂移或大时间相邻点合并。
2. 积分不再把正的亚微秒时段当作零；会先计入能量再在末端暂停。若当前浮点精度无法让时间继续前进，明确停止。
3. 移除输入先计算候选有效区间。可运行时统一重设时间并清零累计量，可撤销；若恢复的下层数据冲突，则保持原状态并拒绝操作。
4. 读取存档在结构校验后，使用实际禁建判断及同一组坡度采样筛查设备地块。边界测试已证明保护区坐标会拒绝；不宣称地基全覆盖检测。

复现命令见 README。受限环境应指定可写 HOME/XDG 目录并记录对应存档位置。

## C. 数据与物理边界

| 项目 | 当前行为与限制 |
| --- | --- |
| 源优先级 | 直接功率 > 适用专属气象 > 全局气象；未绑定字段才用内置值。自动与实际功率/辐照导入交叉验证，不叠加两份出力 |
| 数据区间 | 实际消费的数据决定共同区间；导入或移除输入成功后从区间起点开始、累计量归零；不兼容修改原子拒绝 |
| 时间积分 | 左值保持、≤1 秒且切分样本边界；小数、大时间和亚微秒边界已回归；内置连续天气仍是数值近似积分。短序列末端 GUI 暂停仍待验 |
| ISO 文件组合 | 每文件独立首条 UTC 为 t=0，保留原点；**不自动按绝对日期对齐**，需导入前同步基准 |
| 新导入额定值限制 | 按当前额定 kW 拒绝超额输入；错误 MW 单位的 GUI 拒绝已观察 |
| 后续降额 | 原测量保留，运行按新额定值削顶；自动验证已通过。普通合法降额 GUI 已验，不等同于“测量超新额定值”的削顶 GUI 场景 |
| 电网 | 发电设备→站→外部电网；每设备一条出线；外部总接收上限 4 MW；不求解 AC 潮流 |
| 风机动画 | 运行态三叶示意，未校准真实转速曲线 |
| 光伏几何 | 压缩场区；当前物理参数无面积/倾角/方位映射，视觉不推算产能 |
| 线路几何 | 实体/拓扑切换不增容；无杆塔、三相结构或地形净空设计 |
