# 1.0.0.1 本轮设备详情相机小修

仅设备详情页相机改变；基地/厂站相机和能源求解保持原样。

- 缩小（滚轮后退）上限为当前模型AABB、旋转姿态、视窗宽高比计算的适配距离的1.6倍。大风机、小泵、扁平光伏不共用固定世界距离，模型不能缩成极小点。
- 拖动始终把模型包围盒中心保留在视窗中央60%的区域；缩放、旋转、窗口尺寸改变后重新约束。无论连续拖多远，不会把整个模型拖出屏幕。
- 放大不增加产品级上限，移除了旧的0.25倍模型半径限制。仅保留max(模型半径×0.0001, 0.00001)的数值安全距离，避免相机越过观察目标或产生退化矩阵；非常近距离允许观察局部，并不保证完整模型仍可见。
- “适配模型”随时恢复完整取景。窗口缩放不再强制重置旋转角度，而是更新缩小与平移边界。
- 所有约束仅是查看器瞬态状态，不写参数、库存、连接、时钟或存档。

版本命名遵循 [VERSIONING.md](VERSIONING.md)。此次是1.0.0.1内的小改提交，不新建V23.1，不覆盖冻结V23源码包。

验收：新增23,522项断言通过，覆盖21类×两尺寸制式×两分辨率，200次缩小/放大、极端连续平移、旋转、窗口改变、重置及权威模拟状态不变；原详情1021项、入口107项也通过。真实云桌面Godot运行窗口显示1.0.0.1，连续两轮4000px滚轮缩小稳定在56.008（适配35.005×1.6）；两次连续长拖后模型中心575.2/481.6位于719×602视窗的80%/80%边界，没有消失。上述结果来自已验收源码随附的原始回归日志及原生 GUI 验收记录，合计 23,522 + 1,021 + 107 = 24,650 项断言，0 失败。本公开源码不包含该次运行日志、截图、状态或实时遥测；公开整理未重新运行测试，也不代表全部历史测试或跨平台导出已验证。
