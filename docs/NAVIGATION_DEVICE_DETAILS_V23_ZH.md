# V23：左键平移与全设备二级详情

日期：2026-10-21。基于完整 V22 独立复制开发。V22 原目录没有改动。公开基线见 [V22 提交](https://github.com/Mackice1/basin-energy-game/tree/b06d64f85271a3a568205c89b146bc1e2cd35e71)。本公开副本只调整证据引用与出处说明，功能及验收范围沿用原 V23 文档。

## 使用
- 基地及厂站内的选择/浏览模式：按住左键拖动平移视角；小幅抖动仍视为单击，松开时选中。
- 主场景阈值 6 px，厂站 5 px，设备详情 4 px。拖动后不选中、不放置、不移动设备。
- 左键从UI区域起拖不会穿透。焦点丢失、模式切换及弹窗会清除手势。
- 中键平移、右键旋转、滚轮缩放和既有键盘导航保留。
- 要移动设备，先显式选择“移动”，再拖动或点击目标位置；默认拖动不再移动设备。
- 单击设备后点“进入设备详情”，或双击设备进入。站内同样有“查看设备详情”入口。
- 详情为大尺寸独立二级页：左侧真实已有3D资产，右侧运行、参数、连接、边界四分区。右拖旋转、左/中拖平移、滚轮缩放；“适配模型”恢复完整取景。
- “返回上一级”或 Escape 关闭详情。由厂站进入时，原厂站窗口、选择和相机保留；由基地进入时回到基地。

## 覆盖范围
完整设备目录21类：风机、光伏、变电站、用电需求、电池、电热水锅炉、燃气热水锅炉、太阳能集热器、储热罐、隔离换热器、热需求、槽式聚光集热器、高温导热油储热、油水换热器、蒸汽发生器、汽轮发电机、蒸汽冷凝器、给水泵、塔式熔盐接收器、双罐熔盐储热、熔盐蒸汽发生器。

电热站、运行塔站及未投运塔站继续使用各自既有场景。电热站原建设、布置、连接、库存及内部操作没有被通用查看器替代。未投运塔站继续明确无运行设备和能量端口，不新增发电能力。

详情页不伪造机舱、建筑、电芯、锅炉或汽轮机的可操作内部结构。逐类展示当前已建模口径和未建模边界。模型来自已有资产，不新增能源技术。

## 数据与状态
- 运行值直接读取主场景最新 result.devices；没有值时明确显示无结果，不制造数值。
- 参数来自当前设备而不是模板；库存来自当前设备 state；端口来自目录；连接来自当前实际 links。
- 参数来源沿用参数表已有说明。单位、比例、温区及模型限制明确显示。
- 查看器不单独计算，不保存第二套库存，不修改主场景时钟。主模拟运行时详情按定时器更新；原来暂停则仍暂停。
- 进入、返回、旋转、平移、缩放不会改变存档状态。删除/恢复时清空旧结果并重建有效模型。
- 隐藏详情时停止其3D渲染，避免隐藏页面持续消耗图形资源。
