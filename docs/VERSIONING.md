# 版本命名

集中版本源为 project.godot 的 application/config/version，当前为 1.0.0.4；运行窗口从该字段读取并显示版本，不另存第二份版本常量。

格式：主版本.功能版本.修订版本.构建号。
- 主版本：重大架构或兼容性变化。
- 功能版本：一批已验收的新功能。
- 修订版本：一批已验收的修复与改进。
- 构建号：同一修订的正式交付构建。

日常小改使用Git提交记录，不每改一个点就发布新版本、标签或完整源码包。攒批完成验收后再统一更新版本。历史V22/V23文件名、证据和冻结包保留，不追溯重命名。

application/config/name保持原值，避免Godot的user://存档目录因显示版本变化而迁移。窗口标题显示集中版本字段。
