# Retained regression fixtures

Only compact synthetic day/night GLPK requests/results, a legacy model hash receipt, and the original dummy-display configuration are retained here. Solver diagnostic logs have been stripped from the result JSON files; numeric fields are unchanged.

Other subdirectories are empty output destinations for historical test/capture scripts. Runtime state, telemetry, screenshots, recordings and complete historical logs are not published. See [publication notes](../docs/PUBLICATION_NOTES.md) and [validation prerequisites](../docs/VALIDATION_V22.md).
