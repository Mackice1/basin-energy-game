# Equipment preview

`load_battery_models.png` shows the actual new procedural Godot models: battery container on the left and industrial consumer on the right. The meshes were created with `EquipmentVisual.create`, exported through Godot's GLTFDocument and rendered together with Blender Cycles. The preview adds only studio lighting and a background plane. It is an asset inspection render, not a live-game screenshot or a simulation-state display. The battery emblem is a static identifier, not an SOC gauge.
